title=Railroader: Wayman

description=[h2]Work in Progress[/h2]
description=Adds buildable railroad track pieces and tools for creating Railroader routes in Project Zomboid Build 42.
description=
description=Currently under active development. Features, recipes, visuals, and save compatibility may change.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*]Railroader
description=[/list]
description=
description=[h2]Creating and updating track[/h2]
description=[list=1]
description=[*]Build and connect your railroad pieces.
description=[*]Open the Graph Editor with the [b].[/b] key or the [b]G[/b] button on the World Map.
description=[*]Create edges and assign node blocks in travel order.
description=[*]Configure each turnout's throat, through and diverge legs using the edge selectors and start/end directions.
description=[*]Apply the draft. Railroader validates it before Wayman saves the changes.
description=[/list]
description=
description=Requires Railroader's public track registration and edge catalog APIs. Wayman adds its contribution to the [b]main[/b] network under the [b]wayman:[/b] prefix; applying again replaces that contribution in the running world. There is no separate network or Origin tab.
description=
description=Turnout edge selectors include the current Wayman draft and the Railroader network. Labels identify their source: [b]wayman:edge_1[/b], [b]rr:main[/b] or another add-on's prefix. The [b]rr:[/b] label is visual only; original Railroader IDs are preserved. Railroader may reject connections to another add-on's edges.
description=
description=Wayman persists the graph and registers it on world load. In multiplayer only the server registers; clients receive the operative graph from Railroader. Registration errors retain the previous accepted graph and are shown in the editor.
description=
description=Custom turnout interaction uses Railroader's native [b]switch.place[/b] support; no manual Railroader patch is needed in compatible builds. Incomplete turnouts can be saved for later configuration and are omitted from the operative graph.
description=
description=[h2]World Map overlay[/h2]
description=The World Map displays Wayman edges, available node blocks, and the nodes belonging to the selected edge. Use the display options in the Graph Editor to choose which layers are visible.
description=
description=Click an edge on the map to select it in the Graph Editor. Click an available node to select its block, or click a node of the selected edge to select the corresponding edge block. Selected blocks are highlighted, and the editor remains above the map while you work.
description=
description=The [b]G[/b] button on the map opens the Graph Editor. You can also open it with the [b].[/b] shortcut, configurable in the game's [b]Key Bindings[/b] menu.
description=
description=[h2]Graph and node editing[/h2]
description=
description=To edit the nodes of a built Wayman entity, right-click the entity and open its node editor from the context menu. Select a node block to inspect its nodes; supported nodes can be added, removed, reordered, or moved to a world square. Press [b]Apply[/b] to save the entity changes and refresh the graph.
description=
description=Turnout [b]at[/b] and [b]switch[/b] nodes cannot be added or removed. When editing a turnout, open the context menu from its switch square.
description=
description=[b]Recommended:[/b] Back up important saves before experimenting with graph or entity geometry. Incorrect node order, disconnected sections, or invalid turnout assignments can make a route unusable.
description=
