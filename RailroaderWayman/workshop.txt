description=[h2]Work in Progress[/h2]
description=Adds buildable railroad track pieces and tools for creating Railroader routes in Project Zomboid Build 42.
description=
description=Currently under active development. Features, recipes, visuals, and save compatibility may change.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*]Railroader
description=[/list]
description=
description=[h2]Important: required Railroader fix[/h2]
description=[b]NOTE:[/b] Railroader does not currently check the [b]IsoThumpable.isThumpable[/b] property correctly. Without this fix, locomotives will detect your tracks as obstacles and destroy them.
description=
description=Open Railroader's [b]42/media/lua/client/Railroader/RR_ObstacleSweep.lua[/b], find [b]smashableOn()[/b] (around line 448), and change the [b]IsoThumpable[/b] condition to:
description=
description=[code]if instanceof(o, "IsoThumpable") and o:isThumpable() then[/code]
description=
description=Railroader updates may overwrite this manual change, so check it again after updating that mod.
description=
description=[h2]Creating a route[/h2]
description=[list=1]
description=[*]Build and connect your railroad pieces.
description=[*]Open the Graph Editor with the [b].[/b] key. You can change this shortcut in the game's [b]Key Bindings[/b] menu.
description=[*]Create an edge for the route, for example [b]wayman[/b], and assign its node blocks in travel order.
description=[*]In the [b]Origin[/b] tab, select that edge and configure its direction and optional offset.
description=[*]Apply the changes to register the graph and route with Railroader.
description=[/list]
description=
description=Wayman does not automatically spawn a train for a custom route. Once the route is ready, you can spawn a locomotive from the Lua console using the origin edge name:
description=
description=[code]RR.TrainEntity.spawnOnRoute("wayman")[/code]
description=
description=[h2]Extending Railroader's network[/h2]
description=Wayman can also extend Railroader's existing [b]main[/b] network instead of registering a separate route.
description=
description=Select [b]main[/b] as the graph origin. This makes [b]main[/b] available in the switch-leg selectors, allowing Wayman edges and turnouts to connect to Railroader's network. Applying the graph merges the Wayman edges and switches into a preserved copy of Railroader's original graph.
description=
description=A switch leg may also reference an edge managed outside Wayman. Select [b]External[/b] in that leg's edge selector and enter its exact edge ID. External IDs are passed to Railroader without checking whether they exist, so an incorrect ID can produce an invalid graph.
description=
description=Railroader normally manages trains on its main route, but you can also spawn one manually from the Lua console with:
description=
description=[code]RR.TrainEntity.spawnOnRoute("main")[/code]
description=
description=[h2]World Map overlay[/h2]
description=The World Map displays Wayman edges, available node blocks, and the nodes belonging to the selected edge. Use the display options in the Graph Editor to choose which layers are visible.
description=
description=Click an edge on the map to select it in the Graph Editor. Click an available node to select its block, or click a node of the selected edge to select the corresponding edge block. Selected blocks are highlighted, and the editor remains above the map while you work.
description=
description=The [b]G[/b] button on the map opens the Graph Editor. You can also open it with the [b].[/b] shortcut, configurable in the game's [b]Key Bindings[/b] menu.
description=
description=[h2]Graph and node editing[/h2]
description=
description=To edit the nodes of a built Wayman entity, right-click the entity and open its node editor from the context menu. Select a node block to inspect its nodes; supported nodes can be added, removed, reordered, or moved to a world square. Press [b]Apply[/b] to save the entity changes and refresh the graph.
description=
description=Turnout [b]at[/b] and [b]switch[/b] nodes cannot be added or removed. When editing a turnout, open the context menu from its switch square.
description=
description=[b]Recommended:[/b] Back up important saves before experimenting with graph or entity geometry. Incorrect node order, disconnected sections, or invalid turnout assignments can make a route unusable.
description=
